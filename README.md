### Introduction

The systemPipeR project provides a suite of R/Bioconductor packages for
designing, building, and executing end-to-end data analysis workflows on local
machines and high-performance computing (HPC) systems, while simultaneously
generating publication-quality analysis reports.

For additional information, please visit the project site [here](https://systempipe.org/about/project/#core-packages).
